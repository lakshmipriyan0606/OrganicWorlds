# Architectural Decisions Log (DECISIONS.md)

This log records permanent architectural choices to prevent reversing decisions later.

| Date | Decision | Rationale | Alternatives Considered |
|---|---|---|---|
| 2026-10-23 | Use Next.js 15+ App Router | Built-in SSR, server components, automatic code-splitting, and SEO optimization suited for e-commerce. | Vite SPA (less optimal for e-commerce SEO), Remix. |
| 2026-10-23 | Direct Tailwind CSS v4 Theme Integration | Native CSS variable theme integration allows zero runtime CSS overhead while providing design token autocomplete. | Styled Components (runtime overhead), Vanilla CSS alone (slower developer velocity). |
| 2026-10-23 | Approved Homepage as Visual Source of Truth | The "Verdure & Root" design (`screens/active/home.html` / screen `959cc20b23564412b57519c02a2eade2`) was verified and approved by the user. | Older generation screen variations at Y=0 / Y=12032. |
| 2026-10-23 | LocalStorage Cart State with React Context | Provides instant client-side cart updates, offline persistence, and seamless shopping without requiring a live backend session server for this phase. | Redux (unnecessary boilerplate for client cart), Zustand. |
| 2026-10-23 | Google Fonts Pairing: Bodoni Moda & Manrope | Implements the exact luxury organic editorial typography requested in the Master Prompt. | Generic browser fonts, Inter. |
| 2026-10-23 | Three.js WebGL Real-Time 3D Engine | Direct Three.js with canvas ref and procedural textures enables realistic 3D amber vessels, physically based transmission, animated candle flames, and floating botanical pollen without React 19 peer-dependency conflicts. | React-Three-Fiber (has peer dependency issues with React 19), Spline (external runtime dependency), static images. |
| 2026-10-23 | Procedural 2D Canvas Label Textures | High-resolution 2D canvas textures generated in-memory give the 3D vessels genuine, tactile typography, foil borders, and organic credentials without loading external heavy texture assets. | Low-res flat cylinder colors, external image downloads. |
| 2026-10-26 | Adopt Prisma ORM for Data Layer | Type-safe queries, migration system, relational model mapping, and built-in support for SQLite in local development and PostgreSQL in production without code rewrites. | Drizzle ORM (less automated migration ecosystem for dynamic CMS fields), TypeORM, raw SQL. |
| 2026-10-26 | Authoritative Server-Side Pricing & Inventory Validation | Critical security defense: client cart items are merely intent; the server authoritatively recalculates unit prices, discounts, shipping, and tax before creating an order. | Client-side total passing (high fraud risk), trusted cart payload. |
| 2026-10-26 | Self-Contained HTTP-Only Session Auth with bcryptjs | Zero-external-dependency authentication using secure, SameSite HTTP-only session cookies and bcryptjs password hashing. Keeps admin and customer data isolated without requiring external hosted services. | NextAuth/Auth.js (complex adapter overhead with SQLite/Prisma on Next.js 16), Supabase Auth. |
| 2026-10-26 | Razorpay as Primary Gateway for India | Comprehensive native support for UPI, Indian cards, and Netbanking. Server-side HMAC-SHA256 signature verification and raw-body webhook handling with idempotency. | Stripe (limited domestic UPI in India), Paytm, PhonePe. |
| 2026-10-26 | Next.js 16 Partial Prerendering Compliance | Dynamic segments use `export const instant = false` and `<Suspense>` fallbacks without evaluating children to allow static prerendering alongside server streaming. | Disabling Turbopack/PPR, static-only exports. |
| 2026-10-26 | Client-Safe CMS Type Separation | Extracted CMS interfaces and fallback defaults into `src/types/cms.ts` to prevent Node `fs/promises` server imports from leaking into client bundles. | Monolithic service file with conditional browser checks. |
| 2026-10-26 | Constant-Time HMAC Signature Verification | Payment signatures and webhooks validated using `crypto.timingSafeEqual` over SHA256 digests to eliminate timing-attack vulnerabilities. | Standard JavaScript `===` equality comparison. |
| 2026-10-26 | Public Unguessable Tracking Tokens | Each order receives a unique CUID `trackingToken` enabling secure `/track/[token]` access with masked PII without forcing customer login. | Sequential order IDs (easily guessable/scraped), mandatory login for basic shipping status. |
| 2026-10-26 | Strict Fulfillment State Machine | Order fulfillment transitions strictly governed by `ALLOWED_TRANSITIONS` map; automatically attaches timestamps and dispatches notifications on `SHIPPED` and `DELIVERED`. | Unrestricted ad-hoc status editing by administrators. |
